## 📖 About

This repository is a lightweight playground for quick experiments, throwaway prototypes and testing GitHub workflows. It deliberately has no fixed stack, so the contents may change from one commit to the next.

## 🎯 What it is used for

- Trying out new libraries and tools before adding them to a real project.
- Testing branches, pull requests, actions and release flows.
- Keeping small utilities and snippets that do not need a repository of their own.

## 🚀 Getting started

```bash
git clone https://github.com/sanobar20/Demo.git
cd Demo
```

There is no build step yet. Add files, open them with the relevant tool, or use this repo as a template for a new idea.
